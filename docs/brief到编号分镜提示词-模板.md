# Brief → 编号分镜提示词（模板）

用三五句 brief 写出带编号、可粘贴的分镜提示词。格式沿用分镜清单的「一镜一段、四段提示词」。

本模板放在本仓库，只给生成出来的角色片用。不收进正在跑的快讯线，也不进新闻许可门。其中「禁止静帧平移」只约束生成出来的角色镜头；史料静帧做 Ken Burns 或幻灯平移仍可用，本页不改那条产线。

交片检查见配套文件《[交片检查-按镜切片](交片检查-按镜切片.md)》。提示词过关后，测试成片还要再看手脚、挡字和遮罩。必须遵守的短规则见《[生成提示词规则-连续表演](生成提示词规则-连续表演.md)》。

## 1. 输入（三五句 brief）

写清下面这些即可，不要从空白写长稿：

- 片子讲什么
- 角色什么样（锁定设计，不临场改）
- 时长、画幅、镜数
- 风格和表演方式（开拍前一起定，不要先出一版再改质感）

不添加 brief 里没有的情节、道具或台词。

## 2. 必须写进提示词的规则

1. 有跑、跳、翻、滑就必须写连续表演，手脚和重心要动，禁止把整个人当静帧整体平移。此条只约束生成出来的角色镜头；史料静帧的 Ken Burns 或幻灯平移不在此列。
2. 片上的字单独合成，和角色重叠前必须先完整可读，再让人叠上来。
3. 白外套这类浅色衣服不要贴浅色背景硬抠。交片前查破边、破洞、手和口袋脱落。
4. 浅色遮罩破了不要用生成像素去补，重拍或换镜。
5. 可以定格，但必须是动作做到那一帧再停，不能拿一张静帧去挪。海报定格允许静帧，但不要用破边最重的那几张。
6. 纯图形镜（或只有眼睛的近景）不查手脚。

## 3. 每一镜的格式

```
CUT:
时码: 00:00.00–00:00.00
镜类: 纯图形 / 角色表演 / 图形+角色 / 动作后定格 / 海报定格
提示词:
  总规格：画幅、本镜时长、风格、这一镜做什么
  锁定元素：已锁定的角色、服装、光线、场景、片上的字；各镜保持一致
  按秒分镜：连续表演。写清手脚、重心、视线怎么动，写清镜头怎么跟；有字时写明字先完整出现的时刻，再写角色进入或重叠
  禁止项：本镜不准出现的情况（静帧平移、字没读清就挡住、浅色背景硬抠等）
检查:
  手脚重心：不查 / 必须连续动 / 可在动作做到后定格
  字先可读：无字 / 先完整可读再重叠
  浅色遮罩：不查 / 查破边、破洞、手和口袋脱落；破了重拍或换镜，不用生成像素补
```

## 4. 出词后先检查，再生成

- 每镜都能读出具体在做的动作，不是站桩或「缓慢移动全身」
- 该连续动的镜头没有静帧整体平移
- 该先读清的字，出现时机写在被角色挡住之前
- 浅色服装的镜头已标明交片前要查遮罩

检查不过的提示词先改，再送给生成工具。提示词写对了，测试成片仍要按交片检查再看一遍：手脚是不是真的在动，字在重叠前是否完整可读，浅色衣服的边缘是否完整。

## 5. 填写示例（取自 AO 预告 CUT 03，仅作格式示范）

```
CUT: 03
时码: 00:02.00–00:03.10
镜类: 图形+角色
提示词:
  总规格：16:9，1.10 秒，电影感三维。黑底先出巨大白色 AO，再让角色从左冲入并滑过字母基线。
  锁定元素：角色 AO 外形锁定；片上的字是白色 AO；冰蓝速度线。
  按秒分镜：0.00–0.30 先出巨大白色 AO，字必须完整可读；0.30–1.10 她从左连续冲入，双臂摆动、双脚交替蹬地，随即重心下沉滑过字母基线，速度线跟上。
  禁止项：禁止把全身当静帧从左移到右；字未读清前角色不得挡住字母。不要把白外套贴在浅色背景上硬抠。
检查:
  手脚重心：必须连续动
  字先可读：先完整可读再重叠
  浅色遮罩：查破边、破洞、手和口袋脱落；破了重拍或换镜，不用生成像素补
```
