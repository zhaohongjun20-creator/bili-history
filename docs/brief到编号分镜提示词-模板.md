# Brief → 编号分镜提示词（模板）

用三五句 brief 写出带编号、可粘贴的分镜提示词。格式是一镜一段、四段提示词，并附检查项。

给军事号里需要生成角色表演的镜头用。日更成片仍是史料静帧 Ken Burns，不接入 `autopost.py`。范围和必须遵守的规则见 [生成提示词规则-连续表演](生成提示词规则-连续表演.md)。交片检查见 [交片检查-按镜切片](交片检查-按镜切片.md)。

在仓库根目录、配好 `ZHIPU_API_KEY` 之后可以直接出词（走现有 GLM，默认 `glm-4-flash`）：

```bash
python character_shots.py path/to/brief.md
```

写出同目录的 `brief-分镜提示词.md`。不进日更生产线，也不生成视频。

## 1. 输入（三五句 brief）

写清下面这些即可，不要从空白写长稿：

- 片子讲什么（只写 brief 里有的事实，不补史实）
- 角色什么样（锁定设计，不临场改）
- 时长、画幅、镜数（按这条片子自己定）
- 风格和表演方式（开拍前一起定，不要先出一版再改质感）

不添加 brief 里没有的情节、道具、台词、武器或结局。

## 2. 必须写进提示词的规则

这些规则只用于角色表演镜，以及和它重叠的片上字、浅色遮罩。不要拿去改史料配图或 Ken Burns。

1. 有身体表演就必须写连续表演，手脚和重心要动，禁止把整个人当静帧整体平移或推拉。
2. 片上的字单独合成，和角色重叠前必须先完整可读。
3. 浅色军装、装备、旗帜不要贴浅色、雪地、灰墙或网格背景硬抠。交片前查破边、破洞、手和装具脱落。
4. 浅色遮罩破了不要用生成像素去补。重拍或换镜。
5. 可以定格，但必须是动作做到那一帧再停。海报定格允许静帧，不要用破边最重的那几张。
6. 纯图形镜（或只有眼睛的近景）不查手脚。
7. 生成的角色镜须标明是生成表演，不得写成史料实拍或历史照片。

## 3. 每一镜的格式

```
CUT:
时码: 00:00.00–00:00.00
镜类: 纯图形 / 角色表演 / 图形+角色 / 动作后定格 / 海报定格 / 史料静帧
提示词:
  总规格：画幅、本镜时长、风格、这一镜做什么。角色镜写明「生成表演」。
  锁定元素：已锁定的角色、服装、光线、场景、片上的字；各镜保持一致
  按秒分镜：角色镜写连续表演（手脚、重心、视线、镜头怎么跟）。有字时写明字先完整出现的时刻，再写角色进入或重叠。史料静帧则写 Ken Burns 方向（推近/拉远/左移/右移），不要写成角色在动
  禁止项：本镜不准出现的情况。角色镜才写「静帧平移」，并写明不得伪装成史料。史料静帧不要把 Ken Burns 写成禁止项
检查:
  手脚重心：不查 / 必须连续动 / 可在动作做到后定格 / 史料静帧（Ken Burns，不按静帧平移判失败）
  字先可读：无字 / 先完整可读再重叠
  浅色遮罩：不查 / 查破边、破洞、手和装具脱落；破了重拍或换镜，不用生成像素补
```

两类不要混用同一条禁止项。

## 4. 出词后先检查，再生成

- 每条角色镜都能读出具体在做的动作，不是站桩或「缓慢移动全身」
- 该连续动的角色镜头没有把整个人当静帧平移或推拉
- 史料静帧写的是 Ken Burns 方向，没有被标成「禁止静帧平移」
- 角色镜已标明是生成表演，没有写成史料实拍或历史照片
- 该先读清的字，出现时机写在被角色挡住之前
- 浅色服装或旗帜的镜头已标明交片前要查遮罩

检查不过的提示词先改，再送给生成工具。本仓库不附带该生成工具。

## 5. 填写示例

### 5.1 军史格式示例（占位，不是史实稿）

下面两镜只示范「史料静帧」和「角色表演」怎么写在同一份清单里。人物、地点、服装都是占位，不能当成某一场历史的事实。镜数仍以各条片子的 brief 为准，不要套成固定两镜。

```
CUT: 01
时码: 00:00.00–00:04.00
镜类: 史料静帧
提示词:
  总规格：16:9，4.00 秒。已核定史料照片，Ken Burns 推近。
  锁定元素：照片内容锁定，不改像素。人物与地点均为占位，不是史实。
  按秒分镜：0.00–4.00 史料照片推近。禁止写成角色在走。
  禁止项：不要写成角色在走，不要把 Ken Burns 推近写成禁止项。
检查:
  手脚重心：史料静帧（Ken Burns，不按静帧平移判失败）
  字先可读：无字
  浅色遮罩：不查

CUT: 02
时码: 00:04.00–00:08.00
镜类: 角色表演
提示词:
  总规格：16:9，4.00 秒。这是生成表演，不是史料实拍。
  锁定元素：占位军官，黄卡其军装。设计锁定。不是历史照片。
  按秒分镜：军官从左走入，双脚交替，停步后右手平举。手脚和重心连续在动。
  禁止项：禁止全身静帧平移。不要写成历史现场实拍或历史照片。不要补 brief 里没有的武器、台词或情节。黄卡其军装不要贴浅色或灰墙硬抠。
检查:
  手脚重心：必须连续动
  字先可读：无字
  浅色遮罩：查破边、破洞、手和装具脱落；破了重拍或换镜，不用生成像素补
```

### 5.2 AO 预告 CUT 03（仅作格式示范）

这一镜只示范版式。它不表示史料图不能 Ken Burns，也不要求军事史片子做成 13 镜。整片样本见 [示例](examples/AO预告片-分镜提示词-连续表演.md)。

```
CUT: 03
时码: 00:02.00–00:03.10
镜类: 图形+角色
提示词:
  总规格：16:9，1.10 秒，电影感三维。这是生成表演。黑底先出巨大白色 AO，再让角色从左冲入并滑过字母基线。
  锁定元素：角色 AO 外形锁定；片上的字是白色 AO；冰蓝速度线。
  按秒分镜：0.00–0.30 先出巨大白色 AO，字必须完整可读；0.30–1.10 她从左连续冲入，双臂摆动、双脚交替蹬地，随即重心下沉滑过字母基线，速度线跟上。
  禁止项：禁止把全身当静帧从左移到右；字未读清前角色不得挡住字母。不要把白外套贴在浅色背景上硬抠。不得写成史料实拍。
检查:
  手脚重心：必须连续动
  字先可读：先完整可读再重叠
  浅色遮罩：查破边、破洞、手和口袋脱落；破了重拍或换镜，不用生成像素补
```
