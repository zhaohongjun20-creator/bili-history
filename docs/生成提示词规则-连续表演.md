# 生成提示词规则（连续表演）

按 AO 预告片这一轮的经验整理。完整写法见《[brief到编号分镜提示词-模板](brief到编号分镜提示词-模板.md)》。本页只留必须遵守的规则。

本规则不收进正在跑的快讯线，也不进新闻许可门。「禁止静帧平移」只约束生成出来的角色镜头；史料静帧做 Ken Burns 或幻灯平移仍可用。

## 输入与输出

输入三五句 brief：片子讲什么、角色什么样、时长、画幅、风格和表演方式。开拍前把风格和表演方式一起定，不要先出一版再改质感。

输出带编号的分镜提示词，每镜按分镜清单写成：总规格、锁定元素、按秒分镜、禁止项，并附检查项。

## 必须遵守

1. 有跑、跳、翻、滑就必须写连续表演，手脚和重心要动，禁止把整个人当静帧整体平移。此条只约束生成出来的角色镜头；史料静帧的 Ken Burns 或幻灯平移不在此列。
2. 片上的字单独合成，和角色重叠前必须先完整可读，再让人叠上来。
3. 白外套这类浅色衣服不要贴浅色背景硬抠。交片前查破边、破洞、手和口袋脱落。
4. 浅色遮罩破了不要用生成像素去补，重拍或换镜。
5. 可以定格，但必须是动作做到那一帧再停，不能拿一张静帧去挪。海报定格允许静帧，但不要用破边最重的那几张。
6. 纯图形镜（或只有眼睛的近景）不查手脚。
7. 不添加 brief 里没有的情节、道具或台词。

检查不过的提示词先改，再送给生成工具。提示词过关后，测试成片仍须按《[交片检查-按镜切片](交片检查-按镜切片.md)》再看：手脚是不是真的在动，字在被挡住之前是否完整可读，白外套一类浅色衣服的边缘是否完整。
